# Documentation for your office

Give your client **these files** (email, USB, or shared drive):

| File | Best for |
| --- | --- |
| **`Godown-Ledger-Client-Training.pdf`** | Owner and bookkeeper — print or share on WhatsApp |
| **`CLIENT-TRAINING-GUIDE.md`** | Same content in editable Markdown (trainers) |
| **`CLIENT-HANDOVER.md`** | Launch-day rules, PIN desk, Excel tabs, support |
| **`SOFTWARE-GUIDE.html`** | Open in Chrome → **Print → Save as PDF** for a custom printout |

## How the client should learn

1. Owner reads **CLIENT-HANDOVER.md** (15 minutes).
2. Run **Session A–G** in **CLIENT-TRAINING-GUIDE.md** §14 with real (or copy) data.
3. Keep the **daily checklist** (§4) at each desk.
4. After go-live, first week: owner reviews **Evening close** every night.

## Trainer tip

Demo on the **same HTTPS URL** as production when possible. If you train on a demo server, say clearly that PINs and numbers differ from live.
