# Lahore office computers

For this client installation the application is hosted in the cloud. Windows PCs do not run a second server and do not need Node.js or PostgreSQL. Open the company's final HTTPS address in an up-to-date browser, use the shared mill login, then your own PIN. Add a desktop shortcut to that address if desired.

See [Client handover](docs/CLIENT-HANDOVER.md) for daily work and [Hostinger deployment](docs/HOSTINGER-DEPLOYMENT.md) for installation by the implementer. The office needs Internet access; closing a PC does not stop the hosted system. Do not use the old local poultry installer or its database.
